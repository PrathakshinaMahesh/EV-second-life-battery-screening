# Rapid and Reliable Screening of Retired EV Batteries for Second-Life Applications

## Project Overview

Electric vehicle (EV) batteries are retired from automotive use when their performance is no longer suitable for vehicle requirements. However, many retired batteries may still retain useful energy-storage capability and can potentially be repurposed for stationary applications such as renewable-energy storage, backup power and commercial energy storage.

Before repurposing, these batteries need to be screened and graded to determine their safety, State of Health (SoH), performance and suitability for a second-life application.

This project investigates the **challenges and limitations of existing screening methods for retired EV batteries** and explores the opportunity for a faster, reliable and scalable screening approach.

---

## Problem Being Investigated

Current second-life battery screening methods involve trade-offs between:

* Testing time
* SoH assessment accuracy
* Testing cost
* Scalability
* Battery-to-battery variation
* Availability of historical battery data

Traditional full charge–discharge testing can provide useful capacity information but requires considerably more testing time. Rapid diagnostic methods such as EIS, ICA and pulse-based testing can reduce testing time, but their performance may depend on battery chemistry, temperature, degradation condition and available reference data.

Therefore, the key problem investigated is:

> **How can retired EV batteries be screened efficiently while maintaining sufficiently reliable health assessment for second-life applications?**
